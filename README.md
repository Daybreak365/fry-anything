# 🍤 바삭 연구소
![Develope](https://img.shields.io/badge/개발기간-3시간-blue)
### 사진도, 그림도. 무엇이든 노릇하게.

바삭 연구소는 내가 고른 이미지를 재료 직접 튀김을 만들고, 완성된 튀김을 3D로 갈라보는 웹앱입니다.
인터넷에서 이미지 튀기기가 유행하는 것을 보고, 내가 원하는 기능들을 넣은 나만의 버전으로도 만들어보고 싶다는 생각에서 시작한 프로젝트입니다.

**직접 튀겨보기**  https://daybreak365.github.io/fry-anything/

## ✨ 주요 기능

| 기능 | 설명 |
|---|---|
| **이미지 로드** | PNG·JPG·WEBP·GIF 이미지를 불러와 재료로 사용합니다. 감자·새우·얼음 샘플로도 바로 시작할 수 있습니다. |
| **배경 정리** | 단색 배경 자동 제거, 클릭 지우기, 지우개·복구 붓, 복잡한 배경 정리를 위한 스마트 분리를 제공합니다. |
| **튀김옷 선택** | 가벼운 튀김옷, 바삭한 빵가루, 두툼한 크리스피 중 하나를 택하고 두께를 1~5겹으로 조절합니다. |
| **실시간으로 튀기기** | 이미지를 마우스로 잡아 기름 위에 띄워두면 튀겨집니다. |
| **3D로 자세히 보기** | 완성된 튀김을 회전·확대하고, 단면을 확인합니다. |
